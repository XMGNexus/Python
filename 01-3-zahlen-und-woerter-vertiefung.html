Datentypen bestimmen

  • Bevor du den Code ausführst: Schreibe jeweils als Kommentar unter jede Zeile, um welchen Datentyp es sich handelt. Gib auch einen kurzen Grund an!
  • Führe dann die jeweilige Codezeile aus, um deine Vermutung zu überprüfen.
  • Benutze zu Beginn deiner Python-Datei einen Docstring, der den Zweck der Datei beschreibt.
"""
Bestimmung der Datentypen der Werte, die an die Funktion `print` übergeben werden.
"""

print(type("Deutschland schießt ein Tor."))
# Was ist der Datentyp von "Deutschland schießt ein Tor."? Warum?

print(type('c'))
# Was ist der Datentyp von 'c'? Warum?

print(type(-7))
# Was ist der Datentyp von -7? Warum?

print(type("19"))

print(type(13.9))
# Was ist der Datentyp von 13.9? Warum?

print(type("Quatsch"))
# Was ist der Datentyp von "Quatsch"? Warum?

print(type("a"))
# Was ist der Datentyp von "a"? Warum?

print(type('ABC'))
# Was ist der Datentyp von 'ABC'? Warum?
