Kapitel 1: Zahlen und Wörter – Glossar

Datentypen

Alle Programmiersprachen – auch Python – teilen Daten in sogenannte Datentypen auf. Zu Beginn lernen wir die grundlegenden Datentypen kennen, die in Python vorkommen. Diese sind:

Datentyp Beispiel Beschreibung
Integer Ganzzahlen 5, -17, 0
Float Fließkommazahlen 3.14, -2.718, 0.0
String Zeichenketten in einfachen, doppelten oder dreifachen Anführungszeichen "Hallo", 'Gymnasium Hückelhoven', "4711", """mehrzeilig""", '''oder so mehrzeilig'''
Boolean Wahrheitswerte (wahr oder falsch) True, False

Python ist – wie z. B. JavaScript auch – eine dynamisch typisierte Programmiersprache. Das heißt, dass Python den Datentyp einer Variablen automatisch erkennt und zur Laufzeit, d. h. während der Ausführung des Programms, zuweist. Daher muss man den Datentyp einer Variablen nicht explizit angeben, wenn man sie erstellt. Es ist jedoch hilfreich für dich und deine IDE, den Datentyp als Typenhinweis anzugeben. So vermeidest du selbst Fehler, machst den Code verständlicher und ermöglichst der IDE, dir bei der Fehlersuche zu helfen.

Typenhinweise erstellt man in Python mit dem Doppelpunkt : hinter dem Variablennamen, gefolgt von dem Datentyp. Zum Beispiel:

"""
Typenhinweise für die grundlegenden Datentypen in Python
"""
x: int = 5
y: float = 3.14
z: str = "Hallo"
wahr: bool = True
falsch: bool = False

print(f"{x} hat den Datentyp {type(x)}")
print(f"{y} hat den Datentyp {type(y)}")
print(f"{z} hat den Datentyp {type(z)}")
print(f"{wahr} hat den Datentyp {type(wahr)}")
print(f"{falsch} hat den Datentyp {type(falsch)}")

Integer

Ein Integer ist ein ganzzahliger Wert, z. B. 0, 17, 138, -27 (bekannt aus der Mathematik: Die Menge der ganzen Zahlen ℤ)

Float

Ein Float, auch Fließ- oder Gleitkommazahl genannt, ist eine reelle Zahl, z. B. 1.3878 oder -137.6 (bekannt aus der Mathematik: Die Menge der reellen Zahlen ℝ)

Achtung: Die meisten Programmiersprachen sprechen Englisch 😊. Deshalb wird als Dezimalzeichen ein Punkt statt eines Kommas verwendet, also 1.2 statt 1,2! Mit reellen Zahlen kann man auch rechnen.

Beachte: Teilt man 2 ganzzahlige Werte, dann ist das Ergebnis meistens keine ganze Zahl mehr, sondern eine Fließkommazahl (float), z. B. 1 / 2 = 0.5!

String

Ein String ist ein Zeichen, Wort oder Satz, d. h. alles, was aus Buchstaben, Ziffern, Leerzeichen oder anderen Sonderzeichen besteht. Ein String wird in einfache oder doppelte Anführungszeichen eingeschlossen:

  • "Das ist ein String :-)", weil der Text in doppelte Anführungszeichen gesetzt ist.
  • '4711'. Strings kann man auch in einfache Anführungszeichen setzen und sie können auch Zahlen – wie hier die 4711 – enthalten.
  • Das ist kein String, weil die Anführungszeichen fehlen!

Strings kann man miteinander verbinden (Fremdwort: konkatenieren). Dazu benutzt man den Operator +.

Zum Beispiel:

"""
String-Verkettung in Python mit dem + Operator.
"""

print("1" + "2" + "=" + "12")
# Ausgabe: 1 + 2 = 12

print("Gymnasium" + " Hückelhoven")
# Ausgabe: Gymnasium Hückelhoven

Boolean

Ein Boolean ist ein Wahrheitswert, der entweder den Wert True (wahr) oder False (falsch) haben kann. In Python wird der Datentyp Boolean mit dem Schlüsselwort bool bezeichnet. Näheres dazu im Kapitel 2.1.

Anweisung

Eine Anweisung ist ein ausführbarer Codeabschnitt, der eine bestimmte Aktion ausführt. In Python wird eine Anweisung in der Regel durch eine Zeile Code dargestellt, die eine Funktion aufruft oder eine Variable zuweist.

"""
Anweisung in Python
"""

# Dies ist eine Anweisung, die die Funktion print aufruft.
print("4711")

# Dies ist eine Anweisung, die eine Variable zuweist.
x: int = 42

Kommentar

  • Einen Kommentar kennzeichnet man mit dem # Zeichen, gefolgt von einem Leerzeichen.
  • Alles, was hinter dem # Zeichen folgt, wird von Python als Kommentar interpretiert. Kommentare werden bei der Ausführung des Programms ignoriert.
  • # print("4711") ist also keine Anweisung, sondern ein Kommentar.
"""
Kommentar in Python
"""

# print("Dies ist ein Kommentar und wird nicht ausgeführt.")
# Kommentare dienen dazu, den Code zu dokumentieren und zu erklären.

Die Funktion print

print ist eine Funktion, mit der man Werte auf der Konsole ausgeben kann.

  • print ist der Name der Funktion.
  • Eine Funktion kann Parameter definieren – das sind Platzhalter für Werte, die beim Aufruf der Funktion übergeben werden.
  • Die tatsächlichen Werte, die beim Aufruf an die Funktion übergeben werden, nennt man Argumente.
  • Die Funktion print ist so programmiert, dass sie eine beliebige Anzahl von Argumenten akzeptieren kann.
  • Wenn keine Argumente übergeben werden, schreibt man einfach print(). In diesem Fall wird nur eine leere Zeile ausgegeben.
  • Wenn Argumente übergeben werden, schreibt man sie in Klammern. Mehrere Argumente werden durch Kommas getrennt, z. B. print("Hallo", 42).
  • Alternativ kann auch ein einzelner zusammengesetzter String übergeben werden, z. B. ein f-String: print(f"Hallo {name}").
  • Eine weitere Alternative ist die Verkettung von Strings, z. B. print("Hallo " + str(42)).

Die Argumente von print können verschiedene Datentypen haben, z. B. String, Integer, Float oder Boolean. Die Funktion print wandelt die Argumente in Strings um und gibt sie auf der Konsole aus.

Beispiele

Codezeile Bedeutung
print() Gibt eine Leerzeile auf der Konsole aus.
print(2) Gibt 2 (als Integer) auf der Konsole aus.
print("Gymnasium") Gibt Gymnasium (als String) auf der Konsole aus.
print("Gymnasium" + "Hückelhoven") Gibt GymnasiumHückelhoven (ohne Leerzeichen) auf der Konsole aus. Hier werden zunächst die beiden Strings zu einem einzelnen String verbunden. Die Funktion print bekommt also einen Parameter vom Datentyp String übergeben.
print("Gymnasium", "Hückelhoven") Gibt Gymnasium Hückelhoven (mit Leerzeichen) auf der Konsole aus. Hier bekommt die Funktion print 2 Parameter vom Datentyp String übergeben. Bei der Ausgabe werden die beiden Parameter durch ein Leerzeichen voneinander getrennt.
print("Gymnasium", 2025) Gibt Gymnasium 2025 (mit Leerzeichen) auf der Konsole aus.
print(f"Gymnasium {name}") Gibt Gymnasium Hückelhoven auf der Konsole aus, wenn name den Wert Hückelhoven hat.

Arithmetische Operatoren und Operanden

Arithmetische Operatoren (auch Rechenoperatoren) genannt, sind spezielle Symbole, z. B. + - * / %, die für mathematische Berechnungen verwendet werden. Die Werte, die durch die arithmetischen Operatoren verknüpft werden, heißen Operanden.

Die folgende Tabelle zeigt die bis jetzt wichtigsten mathematischen Operatoren:

Operator Bezeichnung Bedeutung Beispiel
+ Addition a + b ergibt die Summe von a und b summe = a + b
- Subtraktion a - b ergibt die Differenz von a und b differenz = a - b
* Multiplikation a * b ergibt das Produkt von a und b produkt = a * b
/ Division a / b ergibt den Quotienten von a und b quotient = a / b
% Modulo a % b ergibt den Rest der ganzzahligen Division von a und b rest = a % b
** Exponential a ** b ergibt den **Potenzwert* von a und b potenz = a * b

Beachte: In Python ergibt die Division zweier Ganzzahlen immer einen Float (eine Fließ- / Gleitkommazahl), egal ob das Ergebnis eine reelle Zahl oder eine Ganzzahl ist.

Beispiel: Sowohl das Ergebnis von 1 / 2, also 0.5, als auch das Ergebnis von 2 / 2, also 1, sind jeweils Floats.

Parameter und Argumente

Parameter

  • Ein Parameter ist eine Variable, die in der Funktionsdefinition angegeben wird. Er dient als Platzhalter für die Werte, die der Funktion bei ihrem Aufruf übergeben werden. Parameter definieren, welche Art von Daten eine Funktion erwartet und wie viele.
  • Schreibt man nur print(), werden keine Argumente übergeben, weil nichts in den runden Klammern steht.
  • Schreibt man print("Hallo"), dann ist "Hallo" der Parameter, der angibt, was ausgegeben werden soll.

Argumente

Ein Argument hingegen ist der tatsächliche Wert, der einer Funktion beim Aufruf übergeben wird. Es ist die konkrete Dateneinheit, die an die Stelle des Parameters tritt. Bei der Funktion print() können Argumente verschiedene Datentypen sein, wie zum Beispiel ein String print("Hallo"), ein Integer print(2) oder ein Float print(1.2). Diese Werte werden dann dem entsprechenden Parameter der Funktion zugeordnet und verarbeitet.

Parameter verwendet man also in der Funktionsdefinition und Argumente beim Funktionsaufruf.

Die Funktion type

Um zu erfahren, welchen Datentyp eine Variable hat, kannst du die Funktion type verwenden.

"""
Syntax der Funktion type
"""
zahl: int = 10
wort: str = "Hallo"
kommazahl: float = 3.14
wahrheitswert: bool = True

print(type(zahl))
print(type(wort))
print(type(kommazahl))
print(type(wahrheitswert))

Beispiele

Code Bedeutung Ausgabe
type(5) Gibt den Datentyp von 5 zurück <class 'int'>
type(x) Gibt den Datentyp der Variable x zurück, wenn x = 5 <class 'int'>
type(2 + 3) Gibt den Datentyp des Ergebnisses der Berechnung 2 + 3 zurück <class 'int'>
type(2 // 3) Gibt den Datentyp des Ergebnisses der Berechnung 2 // 3 zurück <class 'int'>
type(2 % 3) Gibt den Datentyp des Ergebnisses der Berechnung 2 % 3 zurück <class 'int'>
type(2 / 3) Gibt den Datentyp des Ergebnisses der Berechnung 2 / 3 zurück <class 'float'>
type(3.14) Gibt den Datentyp von 3.14 zurück <class 'float'>
type("Hallo") Gibt den Datentyp von „Hallo“ zurück <class 'str'>
type(True) Gibt den Datentyp von True zurück <class 'bool'>
type(False) Gibt den Datentyp von False zurück <class 'bool'>
type(2 > 3) Gibt den Datentyp des Ergebnisses der Berechnung 2 > 3 zurück <class 'bool'>
type(2 == 3) Gibt den Datentyp des Ergebnisses der Berechnung 2 == 3 zurück <class 'bool'>
type(2 != 3) Gibt den Datentyp des Ergebnisses der Berechnung 2 != 3 zurück <class 'bool'>
type(True and False) Gibt den Datentyp des Ergebnisses der Berechnung True and False zurück <class 'bool'>
type(True or False) Gibt den Datentyp des Ergebnisses der Berechnung True or False zurück <class 'bool'>

Fehlermeldungen

Fehlermeldungen treten auf, wenn der Python-Interpreter auf ein Problem stößt, das die Ausführung des Codes verhindert. Hier sind einige häufige Fehlermeldungen:

Fehlermeldung Bedeutung Beispiel
SyntaxError Der Code entspricht nicht der korrekten Syntax / Schreibweise. print("Hallo" (fehlende schließende Klammer).
NameError Auf eine nicht definierte Variable wird zugegriffen. print(x) (wenn x nicht definiert ist).
TypeError Ein Wert eines falschen Typs wird verwendet. print("Hallo" + 5) (Versuch, einen String mit einer Zahl zu verketten).
zahl: int = "Text" (wenn zahl als Integer deklariert ist, aber ein String zugewiesen wird). Nur mit einem Linter wie mypy wird ein Fehler angezeigt.
ValueError Ein Wert kann nicht in den erwarteten Typ umgewandelt werden. zahl: int = int("Text")
